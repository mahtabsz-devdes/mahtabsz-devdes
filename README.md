### Featured Projects

**[Apollo — Mock ERP & Quote System](https://apollo.gogogravity.com)** ([repo](https://github.com/mtq01/orbit-v1))
Full-stack Next.js + TypeScript ERP and quoting workflow. Uses the Claude API to parse natural-language product requests into typed order data, with Zod schema validation and role-based access control.

**[Orbit — Accessibility Scanner](https://gogogravity.com/orbit)** ([repo](https://github.com/mahtabsz-devdes/Orbit))
Published Chrome extension that runs Axe-core against live pages via the Chrome Extensions API. Includes a multi-tab interface and a custom keyboard tab-order visualizer. Migrated from JS to TypeScript.

**[Cloudy Toys — E-Commerce Store](https://mahtabsz.com/cloudy-toys)** ([repo](https://github.com/mahtabsz-devdes/Cloudy-Toy-Store))
Custom WordPress/WooCommerce theme built from Figma designs, with reusable templates and block patterns.

**[CineMAX — Movie Database](https://mahtabsz.com/cinemax)** ([repo](https://github.com/mahtabsz-devdes/CineMax))
React SPA consuming the TMDB REST API, with reusable components and dynamic detail pages.
